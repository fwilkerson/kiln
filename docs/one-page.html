Approve it, walk away

Shape a spec with Claude, approve it, and go do something else. kiln builds it in the background with headless Claude Code sessions, holds it to your own checks, and lands it on main as one commit.

Between features, monitors keep your repository in shape: they fix the bugs you file, tidy the code, and keep the docs true.

One Go binary, for macOS.

A check is any script whose last line says whether a fix is due. Name it, an agent and a schedule in kiln.json.

shape a spec

/shape asks what it needs, and three reviewers read the draft before you approve it. Its acceptance tests say what done means, each a Given, a When and a Then.

VERIFY

Two sessions, in two clones: one writes the code, the other the acceptance tests. Neither reads the other's work.

GATE

kiln reads the gate's commands from main, never from the build's checkout, so a build cannot weaken the checks it is held to.

AUDIT

A failing gate, or the audit's findings, go back to the build as a round. Detail A says what happens when rounds run out.
